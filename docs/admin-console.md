# 管理后台

ArkSeek 后台在本机浏览器中提供管理员入口，默认地址 `http://127.0.0.1:8766`。真实模式默认只读，QQ机器人独立运行。`--live --manage` 或 `Start-Admin.ps1 -Live -Manage` 显式启用管理；演示默认开放虚构管理。

| 页面 | 用途 |
|---|---|
| 运行概览 | 请求量/身份/等待卡片、趋势、结果与耗时分布、会话对比；图表点击进入筛选记录 |
| 会话记录 | 筛选群聊/私聊、搜索、浏览历史消息、发言人、回复对象与摘要 |
| 用户与记忆 | 查看独立身份、画像卡片、来源原话/更新时间/保护状态抽屉；筛选被屏蔽项 |
| 请求监测 | 会话/状态/日期/耗时筛选，等待/排队排序、时间线与表格切换、请求详情跳转原会话 |
| 运行日志 | 选择本机日志并查看或搜索末尾片段 |

## 数据口径

群聊记录只覆盖机器人接收并保存的消息。旧消息缺少身份字段时显示未记录。摘要是话题索引，不是独立事实证据。画像页保留被保护规则屏蔽的原存储项，并标明其读取状态。

监测记录在新版机器人启动后写入独立的 `data/admin_monitor.db`。记录请求标识、阶段和计时，不复制消息全文或 prompt。使用有界队列，写入失败不阻止 QQ 回复；丢失事件或过期心跳意味着观测可能不完整。

未结束请求失去近期心跳时显示“状态未确认”。分步耗时可能重叠，不能相加作为总等待。QQ发送失败与处理异常后成功发送错误提示是不同状态。

看板统一北京时间，支持今天、滚动24小时与含今天的7个自然日（截至当前）。总等待包含排队；中位数/P90与分布只使用已结束且计时有效的记录，缺失不计0。发送占比以全部记录为分母，不等于回答质量。身份按群/私聊作用域去重。每个筛选范围最多读取最近10000条，并提示截断、最早记录和丢弃事件；无记录不代表没有使用。

时间线仅展示当前页，连续请求共用时间轴，超过5分钟的活动间隔另起一段并标起止时刻。分页和筛选会隐藏其他请求，不能据此还原完整执行顺序。请求与画像来源尚未绑定唯一消息编号，相关入口打开会话，不提供虚假的精确消息定位。

2026-10-23升级仅扩展数据呈现和只读统计，没有改变机器人、记忆/检索架构或同群串行机制。临时虚构数据测试28项通过，并完成浏览器桌面/窄屏检查。

日志查看最多读取末尾256KB、显示500行；搜索仅覆盖该片段。日志应作为自己的私有数据保存。

## 本机访问

服务只绑定127.0.0.1，检查Host和Origin，不开放跨站读取。后台适用于本机单管理员；远程部署需要另行设计认证、授权和传输保护。

## 后续管理功能

已开放L1画像更正锁定、停用、解除决定、审计与回退；原存储和来源不改，自动抽取不能重写被管理的键。L1停用不等于清除L0摘要、原始聊天或L2索引，不宣称彻底遗忘。维护需停止机器人/CLI，下次启动生效。

运行与配置支持启停本后台持有句柄的进程，维护非密钥配置覆盖值和回退；不接管外部PID，进程存活不代表QQ就绪。停止会中断在途请求。后台重启丢失旧句柄后标为未知，不按磁盘PID接管。新机器人/CLI/构建任务共享OS维护锁，首次使用前需关闭不认识此锁的旧版实例。

知识库支持本机TXT只读元数据、纯文本项目副本的导入/修订/启停/回退，以及独立进程加载资料并同步L3索引；原始科研文件、Zotero和JC不提供修改按钮。真实构建会加载既有来源与模型，可能下载模型；演示仅验证虚构文本切分，不冒充真实向量构建。失败/中断的派生缓存可能需重新构建。

所有写入要求原因、120秒有效的一次性状态预览、核对确认、同源Origin和实例令牌；不接受任意命令或原始文件路径。更正/回退不能静默覆盖后续修改。管理副本/配置/审计在data/admin_control.db，画像决定在memory.db；这些均为私有数据，不纳入公开快照。自行备份时应同时考虑两库的一致性。

后台/管理43项与匿名群结构21项自动测试通过。新增管理页面10-27已在独立虚构环境补做17项常用路径检查；未执行真实QQ启停、真实画像/配置修改或科研知识库构建，不宣称实机已通过。10-28首轮9条真实QQ请求与只读后台接口逐条核对，身份映射及原始聊天不公开。跨层遗忘、热更新、多管理员及更细观测仍为后续范围。
