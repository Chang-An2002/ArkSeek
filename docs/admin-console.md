# 管理后台

ArkSeek 后台在本机浏览器中提供管理员入口，默认地址 `http://127.0.0.1:8766`。第一版只读，QQ 机器人独立运行。

| 页面 | 用途 |
|---|---|
| 运行概览 | 查看会话、消息、画像计数和最近请求 |
| 会话记录 | 筛选群聊/私聊、搜索、浏览历史消息、发言人、回复对象与摘要 |
| 用户与记忆 | 查看独立身份、画像、来源原话、更新时间和保护规则状态 |
| 请求监测 | 查看排队、处理、发送、失败、总等待和并行分步计时 |
| 运行日志 | 选择本机日志并查看或搜索末尾片段 |

## 数据口径

群聊记录只覆盖机器人接收并保存的消息。旧消息缺少身份字段时显示未记录。摘要是话题索引，不是独立事实证据。画像页保留被保护规则屏蔽的原存储项，并标明其读取状态。

监测记录在新版机器人启动后写入独立的 `data/admin_monitor.db`。记录请求标识、阶段和计时，不复制消息全文或 prompt。使用有界队列，写入失败不阻止 QQ 回复；丢失事件或过期心跳意味着观测可能不完整。

未结束请求失去近期心跳时显示“状态未确认”。分步耗时可能重叠，不能相加作为总等待。QQ发送失败与处理异常后成功发送错误提示是不同状态。

日志查看最多读取末尾256KB、显示500行；搜索仅覆盖该片段。日志应作为自己的私有数据保存。

## 本机访问

服务只绑定127.0.0.1，检查Host和Origin，不开放跨站读取。后台适用于本机单管理员；远程部署需要另行设计认证、授权和传输保护。

## 后续管理功能

画像修订、记忆停用与删除需要协调机器人会话锁、后台摘要、内存缓存和派生索引。操作应有影响预览与可追溯记录。机器人启停需要明确进程归属；知识库维护需要区分原始资料和项目副本。这些功能尚未开放。
